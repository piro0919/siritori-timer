# Siritori Timer

> Timer app for Japanese shiritori word-chain game.

[🔗 Live Site](https://siritori-timer.kkweb.io/)

## ✨ Features

- ⏱ Per-turn countdown for time-pressured shiritori
- 🔊 Audio cues (howler.js)
- 🎬 Smooth animations
- 📱 Installable PWA

## 🛠 Tech Stack

- Next.js + React + TypeScript
- Framer Motion
- Howler (audio)
- Serwist (service worker)

## 🚀 Development

```bash
npm install
npm run dev
```

The OG image (`public/ogp.png`) is generated by `npm run build:ogp` from `scripts/build-ogp.mjs`. The fonts in `scripts/fonts/` are subsets that only contain the characters on the image, so re-download them if you change the text.
